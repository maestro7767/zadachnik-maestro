# Задачник Маэстро

Планировщик: планы по отделам «Учёба», «Спорт» и «Быт», календарь, график недели, напоминания, помощник, уровни и испытания, привычки, тренировки, оценки, Помодоро и карточки для повторения.

Данные хранятся в браузере устройства (localStorage), серверной части пока нет. Экспорт и импорт — через JSON-файл в профиле.

## Стек

TypeScript без фреймворка, сборка Vite, тесты на `node:test` (Node 22.6+), линтер ESLint.

## Команды

```bash
npm install
npm test          # автотесты
npm run typecheck # строгая проверка типов
npm run lint      # линтер
npm run build     # сборка в dist/
npm run preview   # локальный просмотр сборки
```

Во время разработки достаточно открыть `index.html` через любой статический сервер (импорты модулей TypeScript обрабатывает Vite при сборке; для живого редактирования — `npx vite`).

## Установка на iPhone

Открыть адрес сайта в Safari → «Поделиться» → «На экран «Домой»».

## Структура

- `index.html` — страница приложения, импортирует модули из `src/`.
- `src/core/` — типы, даты, статистика.
- `src/data/` — модель данных, хранилище с миграциями, экспорт/импорт.
- `src/notifications/` — выбор планов для напоминаний.
- `src/assistant/` — разбор фраз помощника.
- `src/gamification/` — опыт, уровни, испытания дня, серии с заморозкой.
- `src/habits/` — привычки и стартовый набор.
- `src/sport/` — тренировки, подходы, таймер отдыха.
- `src/study/` — расписание, дедлайны, оценки (школа/колледж/вуз), Помодоро, карточки.
- `tests/` — автотесты ключевой логики.
- `docs/modules.md` — описание модулей и история этапов.
