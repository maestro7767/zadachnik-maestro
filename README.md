# Задачник Маэстро

Тёмный планировщик задач на день и неделю с отделами «Учёба», «Спорт», «Быт», напоминаниями и голосовым помощником.

## Возможности

- Планы по отделам: Учёба, Спорт, Быт, с датой и временем.
- Главная: приветствие с аватаркой, полоса недели Пн–Вс, статистика, график выполненного по дням, прогресс за день.
- Календарь месяца с отметками дней, в которые есть планы.
- Заметки для Учёбы и Спорта, сохраняются автоматически.
- Профиль: аватарка, фон карточки (акцент, тёмный или фото), акцентный цвет, тема, аккаунты на устройстве, очистка данных и удаление аккаунта.
- Напоминания: уведомление в момент начала плана, пока страница открыта.
- Помощник: записывает задачи голосом или текстом, понимает «сегодня», «завтра», дни недели, даты и время.
- Устанавливается на экран «Домой» как приложение.

## Запуск

Откройте `index.html` в браузере. Для установки на iPhone разместите папку на любом HTTPS-хостинге, например GitHub Pages, откройте адрес в Safari и выберите «Поделиться» → «На экран «Домой»».

## Структура

- `index.html` — всё приложение: разметка, стили и логика в одном файле.
- `manifest.json` — название и цвета для установки.
- `icon-*.png` — иконки разных размеров. `icon-1024.png` подходит для App Store.

## Данные

Все данные хранятся в localStorage браузера на этом устройстве. Серверной части нет, поэтому планы не синхронизируются между устройствами.

## Ограничения

- Вход через Apple и Google пока не подключён.
- Без сети страница не открывается: офлайн-режим не реализован.
- Push-уведомления, когда приложение закрыто, требуют нативной сборки.
