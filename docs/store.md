# Материалы для магазина приложений

## Название
Задачник Маэстро

## Короткое описание (до 80 символов, Google Play)
Планы на день, учёба и спорт — с ИИ-помощником, уровнями и друзьями

## Полное описание

Маэстро — планировщик дня, который превращает рутину в игру.

ЧТО ВНУТРИ

• Планы на день и календарь — быстрое добавление, напоминания, перенос несделанного на завтра одной кнопкой
• ИИ-помощник — скажи «сдам экзамен по математике через 3 недели», и Маэстро сам разложит цель на шаги по дням, обходя занятые
• Учёба — расписание, оценки, дедлайны, карточки для запоминания, таймер помодоро
• Спорт — тренировки, подходы, привычки, отдых между сетами с таймером
• Игра — опыт, уровни, монеты за выполненные планы, магазин аватарок и тем, серии дней с «заморозкой»
• Вместе — общие списки задач с семьёй и друзьями: комнаты по коду приглашения и недельные челленджи
• Облако — синхронизация между устройствами, работа офлайн, пуш-напоминания

КОНФИДЕНЦИАЛЬНОСТЬ

Без рекламы и трекеров. Локальный режим вообще без аккаунта: данные не покидают устройство.

## Сборка APK
- Автоматически: GitHub Actions, workflow «Android APK» → артефакт `maestro-debug-apk`
- Локально: `npm run android:sync`, затем открыть папку `android/` в Android Studio → Build APK

## Осталось перед релизом в Google Play
- [ ] Скриншоты (2–8 шт., с телефона: главная, помощник, учёба, спорт, вместе)
- [ ] Значок 512×512 и feature graphic 1024×500 для консоли Play
- [ ] Подписанный release-AAB: сгенерировать keystore, настроить signingConfig в `android/app/build.gradle`
- [ ] Аккаунт разработчика Google Play ($25)
